Project Overview

Add-on ผู้ช่วย AI ที่ฝังอยู่ใน Gmail, Google Docs และ Google Sheets

  • สรุปอีเมล/เอกสารด้วย Gemini AI ภายใน 15 วินาที
  • ร่างข้อความตอบกลับ (เป็น Draft เท่านั้น — HITL)
  • ผู้ช่วย AI บน Sheets (วิเคราะห์/สูตร/แปล/กราฟ/แก้สูตร)
  • Dashboard ติดตามการใช้งาน + Health Check
  • CI/CD แบบ code-first (TypeScript + clasp + GitHub Actions)

Problem & Solution

Problem

  • อ่านอีเมล/เอกสารยาวเสียเวลา
  • ต้องสลับเครื่องมือหลายตัว
  • สูตร Sheets พังไม่รู้จะแก้อย่างไร
  • พัฒนา GAS ผ่าน Web Editor ควบคุมยาก

Solution

  • AI สรุป/ร่าง/แปลในที่เดียว (Add-on)
  • ผู้ช่วย AI บน Sheets แก้สูตรให้อัตโนมัติ
  • Code-first (TypeScript + Git + CI/CD)
  • Dashboard ติดตาม + Health Check

Business Workflow

เปิดอีเมล/Sheets → กด Add-on → เลือกฟังก์ชัน (สรุป/ร่าง/แก้สูตร)

▼
ตรวจ Sensitive Data → ส่ง AI (Gemini/OpenRouter) → แสดงผล/ยืนยัน

▼
บันทึก Log (Audit) → Dashboard อัปเดต

Role Workflow

End User (พนักงาน)

เปิดอีเมล → กดสรุป/ร่าง → ตรวจผล → ส่ง Draft เอง

เปิด Sheets → เลือก cells → กดวิเคราะห์/แก้สูตร/กราฟ

Admin

ตั้ง Config (allowed domains, banned keywords)

ดู Dashboard + Audit Log + Health

จัดการ Prompt Template

Developer

เขียน TypeScript → push → deploy (clasp)

ดู Deployment Log + CI/CD

Automation Owner

สร้าง Job (ตั้งเวลาให้ AI ทำงานอัตโนมัติ)

ดู/หยุด/ลบ Job จากหน้า Admin

ER Diagram (Data Model)

Logs
PK: logId
timestamp, userMasked
jobType, model, status

Config
PK: key
value, category
updatedBy, updatedAt
Prompts
PK: templateId
name, taskType, lang
promptText, active
Jobs
PK: jobId
FK: templateId → Prompts

triggerId, status
Dashboard
PK: period (YYYY-MM)
aiCalls, tokensUsed
failures, urlFetchCount
Deployments
PK: deploymentId
version, releaseNote
deployedAt, status
ความสัมพันธ์: Jobs.templateId → Prompts (1:N) | Jobs → Logs (1:N per run) | Logs → Dashboard (aggregate)
