5. คู่มือการใช้งาน

5.1 สรุปอีเมลด้วย AI (Gmail Add-on)

  1. เปิด Gmail → เปิดอีเมลที่ต้องการสรุป
  2. กดไอคอน "AI Workspace Assistant" ด้านขวา
  3. เลือกภาษา (ไทย / English)
  4. กดปุ่ม "สรุปเนื้อหา"
  5. รอ 5-15 วินาที → เห็นผลสรุปจาก Gemini ในการ์ด

5.2 ร่างข้อความตอบกลับ (Gmail Add-on)

  1. เปิดอีเมลที่ต้องการตอบ
  2. เลือกโทน (ทางการ / กระชับ / เป็นมิตร)
  3. กดปุ่ม "ร่างข้อความตอบกลับ"
  4. AI สร้างเป็น Gmail Draft → ตรวจแก้ → กดส่งเอง

ระบบไม่ส่งอีเมลออกโดยอัตโนมัติ (Human-in-the-loop)

5.3 ทดสอบ AI จากหน้าเว็บ

  1. เปิด Web App → แท็บ Admin
  2. วางข้อความในช่อง "ทดสอบ AI"
  3. เลือก สรุป/ร่าง + ภาษา + โทน → กด "ส่งให้ AI"
  4. เห็นผลจาก Gemini ด้านล่าง

5.4 สร้าง Automation Job

  1. หน้า Admin → "สร้าง Automation Job ใหม่"
  2. เลือก Prompt Template + ความถี่ (รายวัน 08:00 / รายชั่วโมง)
  3. กด "สร้าง Job"
  4. ผลลัพธ์เขียนลง Google Sheet แท็บ "AutoResults"
  5. หยุด/ลบ Job ได้จากตาราง "Automation Jobs" ด้านล่าง

5.5 Dashboard

  • แสดง AI calls / Tokens ที่ใช้ / Failures / Provider
  • ข้อมูล auto-refresh ทุก 30 วินาที (ไม่ต้อง reload)
  • แสดง Log ล่าสุด + Deployment Log

5.6 จัดการ Config

  • หน้า Admin → ตาราง Config → แก้ค่าแล้วกด "บันทึก"
  • banned_keywords = คำต้องห้ามส่ง AI (คั่นด้วยจุลภาค)
  • mock_mode = true (ใช้ mock) / false (ใช้ Gemini จริง)
  • gemini_model = ชื่อโมเดล AI ที่ใช้

5.7 Health Check

  • แท็บ Health → ตรวจสถานะ READY / NOT READY
  • ตรวจ: API Key, Spreadsheet, Allowed Domains, Provider

6. ความปลอดภัย

Human-in-the-loop
AI ไม่ส่งอีเมลเอง — สร้างเป็น Draft เท่านั้น ผู้ใช้ต้องกดส่งเอง
Sensitive Data Filter
ตรวจ banned keywords ก่อนส่ง AI — เตือนและขอยืนยันก่อน
Secret Management
API Key อยู่ใน Script Properties เท่านั้น ไม่ hardcode/ไม่ commit ลง Git
Audit Log
บันทึกทุกการเรียก AI (ไม่เก็บเนื้อหาส่วนบุคคล — PDPA)

7. สำหรับนักพัฒนา

คำสั่งทำอะไร
npm run verifytypecheck + lint + test (ตรวจทั้งหมด)
npm run buildesbuild bundle → dist/Code.gs
npm run pushbuild + clasp push (dev)
npm run deploybuild + clasp deploy + บันทึก Deployment Log อัตโนมัติ
npm testรัน unit tests (Jest)
npm run test:pbtรัน property-based tests (fast-check)

โครงสร้างโปรเจกต์ (หลัก)

src/
  addon/        → Add-on UI (CardService)
  webapp/       → Web App (Dashboard/Admin/Health)
  services/     → Business logic (Summary, Draft, Automation, Prompt, Monitoring, Health)
  ai/           → AIProvider (Gemini / Mock)
  security/     → Auth, SecurityFilter
  data/         → Repositories (Google Sheets)
  core/         → Config, Secret, Logger, Errors, Retry
  types/        → Shared TypeScript types
tests/          → Jest + fast-check (25 tests)
dist/           → Build output (clasp push จากที่นี่)
